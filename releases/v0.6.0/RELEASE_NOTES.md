# xixi v0.6.0

### 新增

- 支持在账号云端加密托管模型 API Key，由同步服务代为调用支持的模型；可在设置中管理托管配置。
- 知识库截图可在用户明确授权后同步到账号私有 OSS，并随知识库记录跨设备恢复。
- Agent 增加悬浮快捷指令入口，可快速输入或发送语音和文字指令。
- 应用交互知识可按应用页面、控件和屏幕区域记录用户示教与 Agent 操作结果，并在后续操作时注入相关经验。
- 为复杂界面加入通用布局语义提示和多轮探索策略，帮助 Agent 识别内容分区、尝试滚动、展开/收起并根据界面变化验证结果。

### 改进

- 修复托管模型 API Key 管理接口在云端因请求方法限制返回 403 的问题。
- 优化知识库截图、定时任务与账号同步服务的存储及访问策略。
- 更新无障碍交互、屏幕截图与应用交互知识架构文档。

### 改进

- Agent 增加应用无关的 UI 语义推理知识，将截图与 UI tree 对照为临时语义区域、内容项和待验证关系，不绑定具体控件类型或业务页面。
- 进入目标应用的新稳定页面时，默认在至少两个不同内容区域分别尝试轻量下滑探测，不要求 UI tree 预先标记可滚动；每次尝试后重新观察，并依据界面变化继续探索或停止。
- 复杂界面采用多轮观察闭环：根据每次上/下滑、选择、展开或收起后的截图和 UI tree 变化更新布局关系；连续三轮均无有效变化后再判定滚动边界。
- 完整遍历时按已验证的控制状态分组，并在局部详情读取后恢复原状态再继续，减少跨分组混读和内容位置变化导致的漏项。
- 应用交互知识增加控件/区域级历史动作记录，跟随示教可按应用页面、控件标识、语义标签和边界聚合点击/滚动等事件，并在 agent 上下文中按当前应用页面注入。
- 区分动作事件与界面结果验证：无障碍事件只作为“观察到操作”的证据，agent 仍需匹配当前区域并检查操作后的截图和 UI tree，不把动作派发成功误报为操作有效。
