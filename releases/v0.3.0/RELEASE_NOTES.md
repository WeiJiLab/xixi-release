# xixi v0.3.0

## 新增

- xixiFree 增加持久化会话管理，可查看、切换并继续历史任务。
- 增加 Desktop / Cloud 实时远控 Beta，支持画面、点击、滑动以及返回、主页和最近任务。
- 设置页整合模型、远端设备、显示、日志和实验功能。
- 增加聊天截图完整、精简和隐藏三种显示策略，并支持点击放大。
- Agent 增加批量和自适应批量操作，可动态调整连续点击间隔。

## 改进

- Desktop 远程网关优化并发请求与原始 JPEG 画面传输。
- 优化外屏坐标、分辨率、UI Tree 和无障碍手势映射。
- 恢复历史会话时只提供近期上下文，不重复执行历史指令。

## 修复

- 修复停止任务后 LLM、截图、批处理或远端请求仍继续重试的问题。
- 修复远端虚机点击、滑动和拖拽坐标偏移或不生效的问题。
- 修复 Desktop 网关错误选择虚拟网卡地址的问题。
- 修复部分移动端闪退、语音初始化和模型配置丢失问题。

## 已知限制

- 实时远控当前仍以逐帧 JPEG 作为兼容链路。
- 多点触控、捏合缩放和部分系统边缘手势尚未实现。
- system UID Runtime 仅适用于使用对应 platform key 的预配置 AOSP 镜像。
