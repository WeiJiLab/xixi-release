START IN MINUTES

选择你的使用方式

ANDROID 11+

无需 Root，安装后按引导授权

  1. 下载 APK

    在手机浏览器下载 xixiFree；如系统拦截，临时允许当前浏览器安装未知应用。

  2. 配置模型

    打开设置，选择模型并填写必需的 API Key。高级参数保持默认即可。

  3. 开启无障碍

    根据应用引导开启 xixiFree 无障碍服务和屏幕捕获授权。

  4. 说出目标

    返回会话页，通过文字或按住语音按钮发出第一条任务。

先准备 Android 环境，再安装 Desktop

  1. 一行命令准备环境

    在终端运行下方命令，自动安装 ADB、Emulator 和默认 AVD。

  2. curl -fsSL https://raw.githubusercontent.com/WeiJiLab/xixi-release/main/scripts/setup-desktop-macos.sh | bash

    打开 DMG，把 xixi Desktop Node 拖入“应用程序”。首次启动可在“隐私与安全性”中选择仍要打开。

  4. 启动设备

    在控制台选择默认设备并启动；需要手机连接时，再开启远程访问并按页面配对。
